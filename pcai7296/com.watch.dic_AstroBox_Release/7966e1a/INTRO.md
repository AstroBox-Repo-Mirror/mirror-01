# 腕上词典 — 手环上的离线英汉词典

**全功能说明**

---

## 概述

腕上词典是一款运行在小米手环/手表上的 Vela QuickApp 离线英汉词典。无需联网，抬手即查。词典数据内置在应用中，约 2.8 MiB，覆盖 14,942 条英文词头和 12.2 万中文词组。

---

## 首页

首页提供 4 个主功能按钮 + 2 个辅助按钮：

- **中英查找** — 进入搜索页，输入英文或中文查词
- **查找变形** — 进入变形反查模式（输入 ran 可找到 run）  
- **历史记录** — 查看搜索历史
- **我的收藏** — 查看收藏的单词列表  
- **关于** — 开发信息、词库来源、使用说明、标签/词性缩写表
- **赞助** — 赞赏码页面

首页自动检测屏幕类型，支持胶囊屏（212×520）、方屏（192×192/336×336/432×432）、圆屏（466×466）三种布局。

---

## 搜索

- **全键盘英文输入** — QWERTY 键盘，支持 T9 九键切换
- **光标编辑** — 左右光标移动、退格删除、清空全部
- **实时自动补全** — 输入时动态显示候选词列表，按考试标签排序（中考 > 高考 > CET4 > CET6/考研 > TOEFL/IELTS > GRE），最多 30 条
- **一键触发补全** — 点击候选词直接输入
- **超长文本跑马灯** — 输入超过 5 字符（胶囊屏）时自动滚动显示
- **三击搜索框** — 进入扩展输入模式（大键盘/符号面板）
- **输入验证** — 自动检测英文混中文、非法字符
- **变形模式搜索** — 首页点「查找变形」进入，仅接受英文输入
- **键盘震动反馈** — 可选开启按键震动
- **手动/自动隐藏键盘** — 点击输入框切换，从详情页返回时可自动隐藏
- **返回手势** — 从屏幕左侧向右滑返回

## 查词结果

支持 4 种搜索模式，结果上限 20 条，分页显示（超过 20 条时可翻页）：

### 英文精确/前缀匹配
- 按首字母定位到 26 个词库分片文件
- 精确匹配优先，前缀匹配次之
- 匹配结果附带考试标签、音标、释义

### 中文查词
- 单字检索 — 直接查单字关联的中文词组  
- 多字词组精确/前缀匹配 — 按 Unicode codepoint % 64 分桶定位
- 中译英 — 支持中文查英文（通过 cn_index 索引反向匹配）
- 单字和简短词组快速查英文释义

### 变形反查
- 支持英语动词、名词、形容词的形态还原
- 输入 ran → 找到 run（过去式 → 原形）
- 输入 better → 找到 good（比较级 → 原级）
- 输入 feet → 找到 foot（复数 → 单数）
- 输入 running → 找到 run（进行时 → 原形）
- 最多 3 层嵌套查词（变形 → 变形 → 变形）
- 反查结果标注「变形」标签
- 无法直接匹配时，自动复用词根释义

### 模糊搜索（混淆容错）
- 基于编辑距离算法（改进型受限 Damerau–Levenshtein），最多容忍 2 字符差异
- 扫描范围：跨全部 26 个字母分片，≤4000 词
- 候选池：最多 80 个候选，按距离+考试标签排序
- 自动降级触发：精确+前缀匹配无结果时自动启用
- 结果标注「相近结果」

### 性能优化
- LRU 分片缓存（entry/word/cn_index 分级缓存）
- 增量渲染：每隔 1 秒刷新显示，防止 UI 卡死  
- 异步分片加载，避免一次性读取大文件
- 已搜索列表缓存，返回到结果页时无需重新搜索
- 历史记录缓存 entry ID，重新搜索时跳过索引扫描

## 单词详情

- **完整释义** — 显示英文单词、音标（支持 IPA 音标编码解码）、中文释义
- **词性标注** — 自动解码词性缩写（vt. vi. n. a. ad. prep. conj. pron. int. num. art. aux. 等）
- **考试标签** — 标记单词所属考试等级（中考/高考/CET4/CET6/考研/TOEFL/IELTS/GRE）
- **变形按钮** — 在当前单词基础上继续「查变形」，1 秒防连点，最多嵌套 3 层
- **收藏切换** — 一键收藏/取消收藏，使用 @system.storage 持久化
- **超长单词跑马灯** — 单词文本超过屏幕宽度时自动滚动
- **自适应布局** — 胶囊屏底部留空白适应圆角（margin-bottom: 40px），圆屏居中按钮

## 收藏

- **容量上限**：150 条
- **自动去重**：相同单词自动跳过，已存在则取消收藏
- **A–Z 字母筛选**：通过 filter 页面按首字母筛选收藏列表
- **分页浏览**：每页最多 20 条，支持上下翻页
- **超长单词跑马灯**：单词长度超过屏幕宽度时自动滚动
- **考试标签显示**：每条收藏展示最高等级的考试标签
- **点击打开详情**：点击收藏条目直接跳转单词详情页

---

## 历史记录

- **容量上限**：20 条
- **条目含缓存 ID**：保存搜索结果的 entry ID 列表，返回结果页时瞬间显示，无需重新索引扫描
- **去重**：相同查询自动移至最前
- **清空全部**：一键清除所有搜索历史
- **分页浏览**：每页文件列表可翻页
- **空状态**：无历史时显示「暂无历史」

## 词典引擎

### 数据规模
| 项目 | 数量 |
|------|------|
| 英文词头 | 14,942 条 |
| 中文词组 | ~12.2 万 |
| 英文分片 | 26 个字母文件 |
| 中文分桶 | 64 个 Unicode 桶 |
| 词条分片 | 30 个 entry 文件 |
| 变形索引 | 26 个文件 |
| 反向变形索引 | 26 个文件 |
| 中文→英文索引 | 96 个文件 |
| 总大小 | ~2.8 MiB |

### 数据压缩（compact-v3 格式）
- **Front Coding** — 英文单词前/后缀压缩，公共前缀仅存 1 个 base36 字符
- **Delta + ULEB128 编码** — 中文索引 ID 列表用差值增量 + base64 宽带编码，大幅减小体积
- **分片存储** — 按首字母/Unicode 模数/entry ID 模数分片，避免单文件过大
- **数据校验** — 运行时对 wire format 做严格格式校验（解码失败时抛 DictionaryFormatError）

### 考试标签体系
8 级标签，按权重参与搜索排序、自动补全排序、模糊候选评分：
zk（中考）> gk（高考）> cet4（大学英语四级）> cet6（大学英语六级）/ ky（考研）> toefl（托福）> ielts（雅思）> gre（GRE）
标签位图存储于词库索引中，运行时解码为可读标签。

### 中文查词引擎
- 输入单字：通过 Unicode codepoint % 64 定位到 64 个分桶文件
- 输入多字词组：按首字定位 + 词组精确/前缀匹配
- 中文→英文双向查词（cn_index 实现中译英）
- 单字检索跳过词组索引，直接走中文分词查词路线

### 变形索引
- 正向索引（inflect_*）：变形 → 原形（含 entry ID）
- 反向索引（ireverse_*）：原形 → 变形（含变形词字符串或 entry ID）
- 2-字符分片键（key_for 函数）
- 变形结果按词库释义优先，词库无匹配则复用原形释义

## 输入法组件（InputMethod）

- **3 种屏幕布局**：圆屏（62-round QWERTY）、胶囊屏（66-capsule 弧形键盘）、方屏（67-square 横排键盘）
- **2 种键盘类型**：QWERTY 全键盘、T9 九键
- **多语言支持**：英文（en）、中文（cn，内置 6763 汉字拼音→汉字映射）、日文（jp，romaji→kana→kanji 映射）
- **联想候选**：实时拼音→汉字候选项、英文补全候选项
- **按键震动**：可配置按键震动反馈
- **显示/隐藏**：通过 props 控制键盘显隐
- **事件驱动**：keyDown → delete → complete → ready 事件序列

## 多屏适配

3 种屏幕形态自动适配，每个页面均有对应 CSS profile：

| 类型 | 典型分辨率 | profile |
|------|-----------|---------|
| 胶囊屏（pill） | 212×520 / 192×490 | pill-standard / pill-compact |
| 圆屏（circle） | 466×466 | circle |
| 方屏（rect） | 336×336 / 432×432 | rect |

- 首页按钮 4 列布局（圆/方屏）/ 单列布局（胶囊屏）
- 结果页卡片宽度圆屏内切于 √2 正方形内避免圆角裁切
- 搜索页命区长度不同屏幕形态不同（圆屏 12 字/方屏 11~15 字/胶囊 5 字）
- 关于页文本按屏宽自适应折行

## 路由与页面

| 路由 | 页面 | 说明 |
|------|------|------|
| pages/index | 首页 | 主菜单 |
| pages/search | 搜索 | 输入法 + 自动补全 + 光标编辑 |
| pages/results | 查词结果 | 英/中/变形/模糊 4 种搜索 |
| pages/detail | 单词详情 | 释义+收藏+变形嵌套 |
| pages/records | 历史/收藏列表 | type 参数区分 |
| pages/about | 关于 | 致谢、词库说明、标签表 |
| pages/sponsor | 赞助 | 赞赏码 |
| pages/filter | 字母筛选 | A–Z 筛选收藏 / 大键盘输入 |

路由特性：
- 详情页→结果页（变形）使用 `router.replace` 而非 push
- 历史页→搜索页使用 `router.replace` 并携带 autoSearch
- 收藏筛选页使用 `router.replace` 更新筛选状态
- 每个页面都实现了 swipe-back 滑动手势返回
- 搜索页禁用系统返回手势（与键盘右滑冲突），使用自定义手势

## 数据存储

### @system.storage

| Key | 类型 | 上限 | 用途 |
|-----|------|------|------|
| dic_history | JSON array | 20 | 搜索历史（含 entry ID 缓存） |
| dic_favorites | JSON array | 150 | 收藏列表（词+音标+释义+标签） |

- 数据以 JSON 字符串序列化存储
- 收藏按添加顺序排列（新收藏在最前），字母筛选后按 A→Z 排序
- 历史按搜索顺序排列（新搜索在最前）
- 启动时自动清理失效的历史条目

## 系统特性

- **纯离线运行** — 无网络请求，词典数据完全内置
- **震动反馈** — 支持按键震动、操作反馈（@system.vibrator）
- **设备信息获取** — 自动检测屏幕形状、分辨率（@system.device）
- **文件读取** — 按需读取分片文件，LRU 缓存减少 IO（@system.file）
- **Toast 提示** — 错误、成功、操作提示（@system.prompt）
- **跑马灯动画** — 超长文字自动滚动
