# CyberDice

## 功能

CyberDice 让手环随时成为一枚骰子。抬腕摇一摇或轻触屏幕，即可开始投掷；骰子会进入摇动状态，随后清晰显示结果，并可用震动提醒确认结果。整个过程在设备上离线完成，适合桌游、聚会、临时决策等场景。

## 交互

- 在首页点击屏幕或摇动手腕即可投掷；摇动持续时保持投掷状态，结束后显示本次结果。
- 首页下→上滑动可查看历史记录，右→左进入功能；所有页面左→右返回。每条记录显示投掷结果、使用的骰子模式和时间；可一键清空全部记录。
- 首页右滑或点击底部的“功能”，可选择 1D6、2D6、3D6、1D20 等常用玩法；也可自定义骰子数量和面数，适应不同桌游规则。
- 设置中可分别开启或关闭震动反馈与动画效果，让投掷体验更符合使用习惯。
- 主题提供科技蓝、极客绿、赛博紫三种强调色，切换后用于结果与选中状态的视觉提示。
- 左滑保留给系统返回或退出应用，避免与手环既有操作冲突。

## 应用适配

CyberDice 已在小米手环 9 Pro 上完成测试。小米手环 9、小米手环 10 和小米手环 10 Pro 尚未完成正式测试，但可尝试安装和使用；若出现显示或传感器体验问题，建议反馈具体设备和现象。

## 开发与编译

应用基于 Xiaomi Vela JS 快应用项目开发，可通过 AIoT IDE 调试并安装到 Vela 虚拟设备或已连接设备。当前已完成摇腕/点击投掷、结果反馈、历史记录、玩法选择、自定义骰子与主题设置。

```bash
npm run build
npm start
```

`npm run build` 编译生成调试包，`npm start` 启动调试并部署到 Vela 虚拟设备。
