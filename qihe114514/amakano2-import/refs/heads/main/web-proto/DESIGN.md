# 甜蜜女友2 导入器 · 视觉设计稿

> 手机优先，iOS HIG 语言。目标：一眼是「这个产品的工具」，不是任何模板。

## 0. 设计意图

这个插件九成的时间在做一件事：**等一章图片传完**。所以视觉的主角是传输本身，
其余三页（存档/统计/设置）都该是安静的背景。界面不该喊你看它——它该让你
瞟一眼就知道「传到哪了、还要多久」，然后把注意力还给剧情。

色彩从女主的瞳孔取：一点暖粉。除此之外全是中性色，像 iOS 自带的应用。

## 1. 色彩

### 语义色板

| 角色 | 值 | 用在哪 |
| --- | --- | --- |
| 背景 | `#161316` | 整页 |
| 分组面 | `#211C20` | 列表组、卡片 |
| 嵌套面 | `#2C2529` | 行内小块、次级按钮底 |
| 主文 | `#F5F0F2` | 标题、数值、章节名 |
| 次文 | `#B8ACB2` | 正文、行内值 |
| 弱文 | `#8A7D84` | 元信息、说明 |
| 强调·粉 | `#E59BB4` | 唯一强调：进度、当前选中、主按钮文字 |
| 主按钮底 | `#C2557F` | 一屏至多一个实心主按钮 |
| 成功 | `#8FBC9B` | 已安装 |
| 警示 | `#D8AE6A` | 断点待续 |
| 危险 | `#D98A7C` | 删除 |

规则：
- **颜色只给数据和状态，不给 chrome**。导航选中靠亮度，不靠粉色填充。
- 状态色是**低饱和**的（粉/绿/黄/红都压暗），深色底上才读得稳。
- 无渐变、无发光、无玻璃模糊——界面是不透明的实色，层次靠**明度台阶**。

## 2. 字体与排版

MiSans（小米，Apache-2.0），三字重：Regular 400 / Medium 500 / Semibold 600。

| 角色 | 字号/字重 | 行高 | 字距 |
| --- | --- | --- | --- |
| 大标题（页名） | 22 / 600 | 1.3 | -0.01em |
| 大数字（总时长/百分比） | 30 / 500 | 1.15 | -0.02em |
| 区块标题 | 13 / 400 | 1.5 | 0 |
| 章节名/行标题 | 15 / 500 | 1.5 | 0 |
| 正文/行内值 | 14 / 400 | 1.6 | 0 |
| 元信息/说明 | 12 / 400 | 1.6 | +0.01em |
| 徽章 | 11 / 500 | 1.4 | 0 |

- 数字统一 `font-variant-numeric: tabular-nums`，跳进度不抖。
- 字距随字号变：大标题收，小字略放。**全篇不用固定字距。**
- 层级靠**字号 + 字重**建立，不靠颜色——颜色是另一套信息（状态）。

## 3. 间距与圆角

- 基础网格 4px。页边距 16px，区块间距 24px，区块内行距 0（靠分隔）。
- 圆角两档：组/卡片 **14px**，按钮/徽章 **9px / 6px**。不超过两档。
- 触摸目标 ≥ 44px。列表行高 64–72px（两行内容）。
- 分组用 iOS 的**成组列表**：一个圆角面装若干行，行间 1px 细分隔线（`--line-soft`），
  组与组之间留白 24px。**不是每行一张卡。**

## 4. 外壳（四页共用，稳定不动）

```
┌────────────────────────────────┐
│  ●icon   甜蜜女友2        手环名│  顶栏 52px：产品图标+名 / 连接状态
├────────────────────────────────┤
│  传输状态区（常驻）             │  平时一行灰字；传输中展开成组
├────────────────────────────────┤
│                                │
│   页面内容（唯一随切页替换区）   │
│                                │
├────────────────────────────────┤
│ 推送  存档  统计  账号  设置   │  底栏五页：线性图标+文字，选中提亮
└────────────────────────────────┘
```

- **传输状态区属于外壳，不属于内容**：切页时它不重建、不进入动画、高度不跳。
- 顶栏/底栏常驻。底栏实心 `#1A1619`，顶部一条 1px 细线，**无 backdrop-blur**。

## 5. 各屏视觉

### 推送
- 顶部**线路筛选**：一排文字 chip，选中项底色 `--soft` + 粉字，其余灰字。可横滑。
- 章节用**成组列表**：每行两行——上行「章节名 + 状态徽章」，下行「体积 · 阅读时长」+ 右侧动作。
  公共资源行带「先同步」徽章，因为它是依赖。
- 传输中的章节在下方出一条 3px 细进度条，与顶部状态区呼应。
- 列表下一个全宽主按钮「同步剩余 N 章」（这是本屏唯一主操作）。

### 存档
- 顶部两个次级按钮（导出/导入）等宽并排。
- 存档成组列表：标题行（章节名 + 槽位徽章）+ 元信息行（场景号 · 时间），右侧读档/删除图标钮。
- 删除是唯一有二次确认的操作，走**底部 action sheet**。

### 统计
- 总时长一个 30px 大数字起头，下面是「累计天数 / 今日 / 单日最长 / 日均」的**键值列表**（不是四宫格卡片）。
- 最近 7 天：每行日期 + 一条 4px 水平条 + 分钟数。零日画空条、值显示「—」。

### 账号（新增）
云存档的归属。这一页回答「我的存档存到哪了、换手机还找得回来吗」。
- **顶部账号区**：AstroBox 头像 + 昵称；未登录时一行说明 + 主按钮「登录 AstroBox」。
  登录是宿主账号，插件不碰密码。
- **同步状态**：一枚状态徽章（未绑定 / 同步中 / 已同步 / 离线 / 失败）+ 上次同步时间。
- **手环绑定**：已绑定显示设备名 + 解绑；未绑定给「6 位绑定码」输入 + 说明
  （在手环 QQ 里发 `#绑定 <码>` 完成绑定）。
- **云端存档**：云端槽位数 / 最近同步的章节，一个「立即同步」次级按钮。
- 视觉延续成组列表，账号区允许一点品牌粉（头像描边），因为这是「个人身份」页。

### 设置
- iOS 设置式成组列表：传输 / 设备 / 日志 / 关于四组。
- 分片档位用分段控件，开关用系统样式，**开关选中色用粉**（全篇唯一的彩色控件）。

## 6. 图标

Lucide 线性图标（ISC），stroke 1.6，尺寸：导航 21px、行内 16px、按钮内 15px。
全部 `currentColor`，不套底色、不放进彩色砖。用图标的地方只有：底栏导航、行内动作、状态行。

## 7. 动效

- **没有页面进入动画**（工具不需要表演）。切页 = 内容区瞬时替换，外壳稳定。
- 进度条宽度过渡 300ms 线性。
- 底部弹层：250ms 上移入，`cubic-bezier(.3,.7,.3,1)`，可点遮罩关闭。
- 按钮按下 `:active` 透明度降到 0.7，即时反馈（pointer-down）。
- `prefers-reduced-motion: reduce` 时弹层改纯淡入。

## 8. 与 Apple HIG 的对应

| 决策 | HIG 依据 |
| --- | --- |
| 成组列表而非卡片流 | iOS 设置/系统应用的标准列表语言 |
| 颜色只给状态与主操作 | HIG「用颜色传达信息，而非装饰」 |
| 底部 action sheet 做删除确认 | HIG 破坏性操作的标准呈现 |
| 底栏选中靠亮度 | HIG 导航应退后，让内容居前 |
| 无进入动画 | HIG「动效应解释层级，不是装饰」 |
| 字重建立层级 | HIG 排版原则，SF/MiSans 同族的中性 grotesk |
